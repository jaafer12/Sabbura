# سبورة — تطبيق أندرويد للرسم والتلوين للأطفال

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) يفتح مباشرة على سبورة بيضاء.
بدون تسجيل دخول، بدون إعلانات، بدون مشتريات، وبدون إنترنت.

## كيف تبنيه

1. افتح **Android Studio** (إصدار Ladybug أو أحدث) ثم `Open` واختر مجلد المشروع.
2. اترك Gradle يُكمل المزامنة (سيحمّل الاعتماديات أول مرة، ويولّد ملفات الـ wrapper تلقائياً).
3. اضغط **Run ▶** لتشغيله على جهاز أو محاكي.

لإنتاج ملف تثبيت:

```
Build ▸ Generate Signed App Bundle / APK
```

- أقل إصدار مدعوم: أندرويد 7.0 (API 24)
- الهدف: API 35

## المزايا

**الرسم**
- تنعيم بمنحنيات تربيعية + قراءة النقاط التاريخية من نظام اللمس (`getHistoricalX/Y`) لخط سلس بلا تقطيع.
- دعم القلم الإلكتروني مع تغيّر سماكة الخط حسب ضغط القلم.
- رفض راحة اليد: أثناء استخدام القلم يتجاهل التطبيق لمسات الأصابع لمدة ثانية.
- إصبع واحد فقط للرسم، ولا تكبير أو تمرير بالخطأ.
- زر ممحاة القلم (إن وُجد) يعمل ممحاةً تلقائياً.

**الأدوات**
- قلم، ممحاة، **دلو تعبئة** (يملأ المساحة المغلقة بلمسة واحدة، ويقف عند خطوط الرسمة).
- ١٠ ألوان، ٣ أحجام للقلم، تراجع، مسح الكل مع سؤال تأكيد بأيقونتين.

**مكتبة الرسومات — ٢٧ صفحة في ٣ تبويبات**
- رسومات: قطة، دب، سمكة، سلحفاة، فراشة، زهرة، سيارة، صاروخ، بيت.
- أشكال هندسية: دائرة، مربع، مثلث، مستطيل، نجمة، قلب، معيّن، سداسي، بيضاوي.
- خطوط تقوية اليد: مستقيمة، أمواج، زجزاج، تلال، لفّات، حلزون، ومسارات ممتعة
  (الفراشة إلى الزهرة، السيارة إلى البيت، السمكة إلى الفقاعات).

الرسمة تُعرض في طبقة فوق التلوين، فتبقى خطوطها واضحة ولا تمحوها الممحاة.

**الواجهة**
- عربية بالكامل واتجاه من اليمين لليسار، وأيقونات بدل النصوص.
- ملء الشاشة (بدون أشرطة النظام) والشاشة تبقى مضاءة أثناء الرسم.
- تخطيط يتكيّف: شريط سفلي في الهاتف، وشريط جانبي في التابلت الأفقي.
- لا يُعاد إنشاء الشاشة عند التدوير، والرسم محفوظ بإحداثيات نسبية فلا يتشوّه.
- اهتزاز خفيف عند اختيار الأدوات.

**الخصوصية**
- لا يوجد أي إذن في `AndroidManifest.xml` — ولا حتى إذن الإنترنت.
- لا يُحفظ أي رسم، ولا تُجمع أي بيانات، ولا يوجد أي اتصال خارجي.

## بنية الكود

| الملف | الوظيفة |
|---|---|
| `MainActivity.kt` | تشغيل التطبيق وملء الشاشة |
| `Ui.kt` | الواجهة كاملة: السبورة، شريط الأدوات، قائمة الرسومات، تأكيد المسح |
| `BoardView.kt` | محرك الرسم: الخطوط، الممحاة، دلو التعبئة، التراجع، تسطيح السجل لتوفير الذاكرة |
| `TemplateRenderer.kt` | رسم القوالب على اللوحة وعلى المصغّرات |
| `SvgPath.kt` | محلّل مسارات SVG مكتوب يدوياً (بدون مكتبات خارجية) |
| `Art.kt` | بيانات الرسومات الـ٢٧ (ملف مُولَّد آلياً) |
| `Icons.kt` | أيقونات الواجهة |

## إدارة الذاكرة
- طبقة تلوين واحدة بحجم الشاشة، وسجل أوامر يُسطَّح تلقائياً بعد ٨٠ أمراً
  (يُدمج القديم في صورة واحدة ويبقى آخر ٢٥ أمراً قابلاً للتراجع).
- قناع حدود دلو التعبئة يُبنى عند الحاجة فقط ثم يُحرَّر.
